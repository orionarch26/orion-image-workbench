# Roadmap

## Shipped in v0.2.0

- English / Simplified Chinese application UI, in-app guides and language preference.
- Locale switching without changing drafts, user data or task submission identity.

## Next: portable runtime

- Separate installed application resources from writable user data.
- Replace Linux-specific application file locks/process inspection with portable implementations.
- Configure an existing local ComfyUI directory and interpreter explicitly.
- Validate native Windows NVIDIA inference; publish platform results honestly.
- Extend bilingual coverage to launcher/CLI diagnostics and additional upstream error mappings.
- Provide clean GPU-environment installation and migration verification.

## Later

- Optional LLM prompt assistant, with manual review and provider validation.

- Stable Python package/release builds with included resources.
- Additional model adapters after independent validation.
- Portable recipes with explicit reference-asset handling.
- Improved experiment evaluation and preset organization.

Remote multi-user serving, multiple concurrent GPU workers and arbitrary node editing are not current release promises.
