# Community code of conduct

Treat contributors and users respectfully. Critique ideas and implementations, explain disagreements with evidence, and help newcomers provide useful reproductions.

Harassment, threats, discriminatory insults, sexual harassment, and publishing someone's private information are not welcome. Do not share personal image galleries or private prompts without permission.

Maintainers may edit or remove abusive content and restrict participation when necessary. Decisions should be proportional and explained to the people involved where practical. For conduct concerns, contact the repository owner through their GitHub profile using an available contact method; do not repost private information in public issues. Security reports belong on the repository Security page.

中文：尊重参与者，围绕事实和代码讨论。禁止骚扰、威胁、歧视、性骚扰以及未经同意公开他人资料。维护者可根据情况移除内容或限制参与；安全问题使用私下安全报告渠道。
