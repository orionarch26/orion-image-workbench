# v0.1.0 — initial public baseline / 首个公开基线

Released: 2026-09-22. This tag freezes the initial application; subsequent features are developed separately. It is an early source release, not a bundled desktop installer.

## Included

- Local creation studio and professional workflow workbench for Qwen-Image-2.1 through ComfyUI.
- Text generation, reference editing, transparent images, sequential batches, durable task tracking and targeted cancellation.
- Controlled parameter experiments, A/B inspection, recipes and preset history.
- Pinned model downloads with resumption, SHA-256 checks and startup guidance.
- English/Chinese README and installation instructions; community files and Apache-2.0 application license.

## Support and validation

- Full application: existing Linux + NVIDIA environment, including an RTX 4070 Laptop with 8GB VRAM. Unit/API and mocked browser tests require no GPU.
- Model downloader: Ubuntu and Windows, Python 3.10 and 3.12 CI. This does **not** establish full Windows application support.
- Application validation: 53 unit/API tests plus browser restore and workbench regression checks. See the release commit's [CI](https://github.com/orionarch26/orion-image-workbench/actions/workflows/ci.yml).
- Model manifest: pinned upstream revisions and SHA-256 values; existing local weights were verified. A fresh end-to-end GPU installation has not been certified.

## Get this exact version

```bash
git clone --branch v0.1.0 --depth 1 https://github.com/orionarch26/orion-image-workbench.git
cd orion-image-workbench
```

Alternatively, download `orion-image-workbench-v0.1.0.zip` from the GitHub release and compare it against `SHA256SUMS`. The source archive includes no model weights, runtime environment, credentials or personal outputs.

Linux archive verification (run in the download directory):

```bash
sha256sum -c SHA256SUMS
```

Windows PowerShell: `Get-FileHash .\orion-image-workbench-v0.1.0.zip -Algorithm SHA256`, then compare with `SHA256SUMS`.

Follow the [English installation guide](../en/installation.md) or [中文安装指南](../zh-CN/installation.md). The separately installed ComfyUI environment and models are still required.

## Known limits

UI text is currently Chinese. Full English UI, full Windows application support and an LLM generation assistant are not part of this version. Model licensing is separate from the application license; see [third-party notices](../../THIRD_PARTY_NOTICES.md).

To return to this version, use a separate checkout of the tag. Back up configuration, task state, outputs and uploaded references before migration. Do not run two application instances against the same database or assume future databases are backward compatible.
