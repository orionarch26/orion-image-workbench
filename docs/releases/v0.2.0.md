# v0.2.0 — bilingual application / 中英文应用界面

Released: 2026-09-22. The creation studio, professional workbench and in-app guides now support English and Simplified Chinese. The v0.1.0 tag remains the original baseline.

## Included / 本次更新

- Persistent **English / 简体中文** selector in the navigation bar; initial selection follows the browser language.
- Translated navigation, controls, help text, placeholders, accessibility labels, task stages, batch controls, recipe history, comparison and known validation errors.
- In-place language switching: prompts, seeds, references, selected results, pending request IDs and active tasks stay unchanged.
- English in-app guides, shared message catalogs, stable error descriptors and browser regression tests.

导航栏可以随时切换语言，设置会保存并在页面之间共享。用户提示词、配方名称、文件名、历史记录不会被翻译；切换语言不会触发出图、取消任务或重建提交请求。

## Download / 下载

```bash
git clone --branch v0.2.0 --depth 1 https://github.com/orionarch26/orion-image-workbench.git
cd orion-image-workbench
```

Alternatively, download `orion-image-workbench-v0.2.0.zip` and verify it against `SHA256SUMS` using `sha256sum -c SHA256SUMS`. Windows: `Get-FileHash .\orion-image-workbench-v0.2.0.zip -Algorithm SHA256`, then compare with the checksum file.

Follow the [English installation guide](../en/installation.md) or [中文安装指南](../zh-CN/installation.md). Model files and the GPU environment are installed separately.

## Validation and limits / 验证与限制

57 unit/API tests, the existing browser recovery/workbench regressions, and the dedicated bilingual browser suite cover the application changes without a GPU. Model downloader CI covers Ubuntu/Windows on Python 3.10/3.12.

Full app support remains Linux NVIDIA; passing Windows downloader tests does not establish full Windows app support. This release does not include the LLM assistant or certify a fresh GPU-runtime installation. CLI diagnostics and unknown upstream errors may retain their original language. No user gallery, credentials, model weights or runtime environment is bundled.

从旧版本升级前请备份配置、state/、output/ 和参考图目录。保留 v0.1.0 的独立检出可以对比代码；不要让两个应用实例同时使用同一任务数据库。生成期间不要更换后端或模型版本。
