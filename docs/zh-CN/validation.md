# 验证范围

原始本地 Linux 环境使用 RTX 4070 Laptop（8GB 显存）、16GB 内存和 Python 3.12。后端与节点版本见[安装指南](installation.md)。

已在该环境验证文生图、原生参考图编辑、透明 PNG、任务恢复、定向取消、高级参数映射、批量提交、配方版本和 A/B 对比。

一次两张图的串行批次使用 768×768、20 步、Euler/Simple、CFG=1，后端执行时间分别为 37.555 秒和 31.991 秒，均未命中采样缓存。后端时间戳确认第二张在第一张结束后开始。这些时间不包括前序任务等待，不是通用速度承诺。

自动测试与 CI 范围见[测试说明](../testing.md)。中英文界面通过模拟任务的浏览器测试验证；这不表示重新验证了 GPU 环境。Windows 完整应用和全新 GPU 环境重建尚未完成验证。仓库不发布个人执行日志或作品截图。
