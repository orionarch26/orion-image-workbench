# Suggested workflow

1. Prepare the backend and model files using the [installation guide](installation.md).
2. Describe the subject, composition, lighting and materials. Start at 768×768 and 20 steps.
3. In the workbench, submit a sequential-seed batch to explore compositions.
4. Load a result's parameters. Keep its seed fixed and vary one parameter, such as steps or CFG.
5. Inspect the A/B comparison, then save the recipe and actual generation parameters.

See the [workbench guide](workbench.md). The 8GB test result applies to the documented configuration; it does not mean every setting fits in 8GB VRAM.
