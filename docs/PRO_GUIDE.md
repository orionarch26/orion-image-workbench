# 专业工作台使用指南

先完成[安装](zh-CN/installation.md)，打开 http://127.0.0.1:7860/pro 。导航栏可切换 English / 简体中文，切换时保留草稿、参考图、种子、提交请求ID及任务跟踪。

## 最快完成一次参数实验

1. 左侧选择快速探索，填写提示词，使用768×768、20步、CFG=1、Euler / Simple。
2. 点击运行按钮上方“批量 / 实验”，选择“连续换种子”，数量3，种子-1。
3. 提交整组。后端逐张运行；任务队列显示批次和每张状态。
4. 选中喜欢的作品，点击“载入参数”，保留它的实际种子。
5. 选择“单变量对比实验”，变化参数选择步数，输入 `20, 30, 40`。
6. 完成后分别设为A和B，查看实际参数差异，选择100%或200%检查细节。
7. 保存命名配方；同名保存保留最近10个历史版本，历史版本可以重新载入草稿。

英文简介：Choose a recipe, submit a sequential seed batch, pick a result, then keep its seed fixed while comparing one parameter. Use A/B to inspect actual differences and save your preferred recipe.

## 参数与参考图

- 默认40步，探索用20步；更多步数不保证更好。
- CFG=1为起点；大于1时负面提示词参与引导，计算成本也可能上升。
- 种子-1表示随机；单变量实验整组只随机一次，所有成员共用实际种子。
- 最多3张参考图，顺序有意义；输出跟随图1比例。上传上限每张20MB。
- 缓存精度不会改变权重量化；实验设置先与默认配置作对比。
- 原生编辑保持denoise=1，不提供像素锁定或遮罩编辑承诺。

## 批次与故障恢复

每批2–5张，与画室共享5个活动任务容量。空间不足整批拒绝，后台不并行执行多个GPU生成。

刷新或关闭浏览器不会取消已登记任务；参数在提交时固定，修改草稿不会改动已提交批次。取消整组只处理本批未完成任务，已完成作品保留。

响应丢失时“重试同一次提交”保留原参数和请求ID。超时或状态不明时“继续核对”查询原任务，不自动重新生成。失败任务可载入原参数，明确点击运行创建新任务。

对比放大后两侧滚动同步相对位置；不同尺寸或构图不代表同一像素位置。

## 配方与导出

配方JSON包含参数和参考文件名，不包含模型或参考图文件。缺少参考图时可先载入草稿，补齐后才能生成。

任务/批次导出保存实际参数、种子与API工作流；它们用于留档，不等同于可直接导入的配方格式。输出和任务库保存在本地，见README的数据说明。
