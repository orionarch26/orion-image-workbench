# Examples

`input_cat.png` is a synthetic reference image. Use it in the workbench's reference-editing mode:

> Keep the cat's appearance and pose. Replace the background with a quiet library at night. Do not add text.

中文：保留猫的外貌和姿势，把背景换成安静的夜间书房，不添加文字。

Use one reference, reference size 512 or 768, Euler/Simple and CFG=1 as a starting point. Consult [third-party notices](../THIRD_PARTY_NOTICES.md) for provenance.
